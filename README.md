# Nemesia Demo

[日本語](README.ja.md)

[Nemesia](https://github.com/tkhshtsh0917/nemesia) adds typo-tolerant query completions to a web page. The demo suggests words extracted from the same documents used for search and offers them while the user types, including during IME composition.

[Open the demo](https://tkhshtsh0917.github.io/nemesia-demo/). Try `bi-t`, `びーt`, or `にh` to see completions for partial Latin and mixed-script input.

- **Add it to your app.** Follow the [browser quick start](docs/browser-quickstart.md) for a plain HTML example, or see the [browser integration guide](docs/browser.md) for the Worker and combobox used in the demo.
- **Run or develop the demo.** Follow [Contributing](CONTRIBUTING.md) for the release download, local build and test commands.
- **Inspect behavior and performance.** See [release and validation](docs/release.md), the [Rust API reference](https://tkhshtsh0917.github.io/nemesia/), and [measured latency and ranking quality](docs/performance.md).
